# Revelado Cultural (Versión 2.0)

> **La cultura del barrio, al descubierto.**
> Plataforma web editorial para visibilizar las 8 iniciativas culturales ganadoras de la convocatoria de Presupuesto Participativo en la Comuna 11 (Laureles–Estadio), Medellín.

---

## 🎨 Características

- **Diseño Editorial Darkroom**: Atmósfera continua en tonos oscuros (`#161317` y `#211820`) inspirada en un cuarto oscuro fotográfico.
- **Tipografía**: Montserrat para titulares de impacto y Roboto para lectura cómoda y legible.
- **Exploración Rápida**: Buscador instantáneo y filtros interactivos por disciplina artística.
- **Multiformato**: Registro fotográfico con visor modal a pantalla completa (lightbox accesible), reels verticales 9:16 y reproductor de audio.
- **Accesibilidad**: Cumplimiento WCAG 2.2 AA verificado con Axe-core (contrastes superiores a 4.5:1, etiquetas ARIA, navegación por teclado y soporte para reducción de movimiento).
- **Rendimiento**: Creado con Vite, React 19, Tailwind CSS v4, Motion y rutas estáticas pregeneradas para SEO.

---

## 🚀 Instalación y desarrollo

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción (incluye generación de rutas SEO)
npm run build

# Ejecutar suite de pruebas con Playwright
npm run test
```
